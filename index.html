외부 앱 및 깃허브(GitHub Pages) 연동 방법

1. 로컬 스토리지 배제 & 외부 클라우드 통신

본 페이지는 브라우저 내부 로컬스토리지(`localStorage`)에만 가두지 않고, Firebase Firestore 원격 데이터베이스 실시간 스트림(`onSnapshot`)과 결합되어 있습니다. 누구나 다른 PC/모바일에서 링크로 접속해도 최신 문의 내역을 동일하게 조회할 수 있습니다.

2. 다른 앱/LLM에서 변수를 사용하는 3가지 방법

  • 변수 복사(JSON): 각 카드 아래 [JSON] 버튼을 누르면 즉시 {title, content, date, ...} 구조체가 복사됩니다.
  • AI 프롬프트 복사: [AI 프롬프트] 버튼을 클릭하면 ChatGPT/Claude 등에 바로 입력할 수 있는 멘토링 템플릿 형태로 복사됩니다.
  • 프로그래밍 방식 연동: 외부 Node.js / Python 스크립트에서도 동일한 Firestore 컬렉션 경로를 구독하여 Webhook이나 API처럼 실시간 데이터를 수신할 수 있습니다.

3. 깃허브 배포 가이드

이 파일명을 index.html로 지정하여 GitHub Repository에 Push한 후, Settings > Pages > Branch: main을 활성화하면 1분 안에 전 세계 누구나 접속할 수 있는 실시간 1:1 문의글 링크가 완성됩니다.
